# 📊 DAX Dashboard Project

A Power BI project focused on using DAX to create measures, calculations, and analytical insights from business data.

## 📌 Overview

This repository contains practical work for learning and applying **DAX (Data Analysis Expressions)** in Power BI.

## 🧠 Topics Covered

- DAX measures
- Aggregations
- Calculated columns
- Filter context
- Basic time and business calculations
- KPI development
- Analytical reporting

## 🎯 Purpose

The project is designed to strengthen DAX and Power BI skills required for interactive business intelligence dashboards and data-driven reporting.

## 🛠️ Technology

- Microsoft Power BI
- DAX
- Data Visualization
- Business Intelligence
